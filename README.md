# Book Store

A React book-store interface with book browsing, book details, account screens and informational pages.

## Included interfaces

- Home, books and individual book-detail routes.
- Login and registration screens.
- About, blog and contact pages.
- Shared layout and not-found route handling.

## Built with

React, Create React App, React Router, Bootstrap and Tailwind CSS.

## Run locally

Install a Node.js version supported by the framework dependencies in `package.json`.

```bash
npm install
npm run start
```

Open the local URL printed by the development server.

## Production build

```bash
npm run build
```
